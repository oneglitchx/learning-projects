🔀 CONTROL FLOW (Decision Engine)
1. Clear Concept Explanation
What is Control Flow?
Control flow determines which lines of code run, when they run, and how many times they run.
Without it, Python is just a straight road. With it, you get forks, loops, detours, and exits.

Core Components
1. Conditional Statements
if → run code if condition is True
elif → check another condition if previous is False
else → fallback when nothing matches
2. Loops
for → iterate over a sequence
while → repeat while condition is True
3. Loop Control
break → exit loop immediately
continue → skip current iteration
pass → do nothing (placeholder)

Why does this exist?
Because programs need to:
Make decisions → “Should I do this or that?”
Repeat actions → “Do this 1000 times”
React dynamically → “Stop if something changes”

Mental Model 🧠
Think of control flow as a game AI brain:
if → decision nodes
for/while → repeated actions
break → emergency stop
continue → skip useless step
You’re not writing code anymore. You’re designing behavior.

2. Core Syntax and Rules
A. Conditional Statements
if condition:
    # runs if True
elif another_condition:
    # runs if above is False and this is True
else:
    # runs if all conditions are False

Rules & Notes:
Indentation defines blocks (VERY important)
Conditions must evaluate to True or False
Python uses truthy/falsy values:      #########################################impp
False, 0, "", [], None → False
Everything else → True
Common Mistakes:
Using = instead of ==
Forgetting indentation
Writing multiple if instead of elif (causes multiple checks unnecessarily)

B. Nested Conditions
if x > 10:
    if x < 20:
        print("Between 10 and 20")

Rule:
Inner if runs only if outer condition is True

C. for Loop
for item in iterable:
    # do something

Examples:
for i in range(5):
    print(i)

Rules:
range(start, stop, step)
Loop runs fixed number of times

D. while Loop
while condition:
    # repeat

Rules:
Runs until condition becomes False
Risk: infinite loop if condition never changes

E. Loop Control
break
for i in range(10):
    if i == 5:
        break

→ Stops loop entirely

continue
for i in range(5):
    if i == 2:
        continue
    print(i)

→ Skips iteration

pass
if True:
    pass

→ Placeholder, does nothing

Internal Behavior (Important Insight ⚙️)
Python evaluates conditions using Boolean logic
Loops create an execution cycle
for uses iterators internally
while checks condition before every iteration

📦 MODULE 3 — Data Structures (Lists, Dicts, Tuples, Sets)

1. Clear Concept Explanation

🔹 What are Data Structures?

Data structures are ways to organize and store data so you can use it efficiently.

Think of it like different types of containers:
- List → a row of boxes, ordered, you can change what's inside
- Dict → a locker room, each locker has a label (key) and content (value)
- Tuple → a sealed box, once packed, you can't change it
- Set → a bag of unique items, no duplicates allowed, no particular order

🔹 Lists
Ordered, mutable collection. Can hold duplicates.
fruits = ["apple", "banana", "cherry"]

Access by index: fruits[0] → "apple"
Slice: fruits[1:] → ["banana", "cherry"]
Modify: fruits[1] = "blueberry"

🔹 Dicts
Key-value pairs. Keys must be unique and immutable.
person = {"name": "Mayank", "age": 17, "city": "Bihar"}

Access: person["name"] → "Mayank"
Add: person["email"] = "test@test.com"
Check: "name" in person → True

🔹 Tuples
Ordered, immutable collection. Like a list that can't change.
coords = (10, 20)
single = (5,) ← note the comma for single-item tuple

Why use them? Faster than lists, safe from accidental changes, can be dict keys.

🔹 Sets
Unordered collection of unique items.
nums = {1, 2, 3, 3, 4} → {1, 2, 3, 4}

Useful for: removing duplicates, membership testing, set operations (union, intersection).

---

2. Core Syntax and Rules

🔹 List Operations
append(x) → add to end
insert(i, x) → add at index
remove(x) → remove by value
pop(i) → remove by index, returns it
sort() → sort in place
sorted(lst) → returns new sorted list
len(lst) → number of items
x in lst → membership check

🔹 Dict Operations
d[key] → get value (error if missing)
d.get(key, default) → safe access
d[key] = value → set/update
del d[key] → delete
d.keys() → all keys
d.values() → all values
d.items() → all (key, value) pairs
key in d → check if key exists

🔹 Tuple Operations
count(x) → how many times x appears
index(x) → position of first x
Tuples support indexing and slicing like lists

🔹 Set Operations
add(x) → add item
remove(x) → remove (error if missing)
discard(x) → remove (no error if missing)
set1 | set2 → union
set1 & set2 → intersection
set1 - set2 → difference

🔹 Nested Structures
Lists inside lists: matrix = [[1,2], [3,4]]
Dicts inside lists: students = [{"name": "A", "grade": 90}, {"name": "B", "grade": 85}]
Lists inside dicts: scores = {"math": [90, 85, 92], "science": [88, 91]}

⚙️ MODULE 4 — Functions (Parameters, Return Values, Scope)

1. Clear Concept Explanation

🔹 What are Functions?

A function is a reusable block of code that does one specific job.

Think of it like a vending machine:
- You put in money (parameters)
- It does its internal work
- It gives you a snack (return value)

🔹 Why Functions?

- Reusability → write once, use many times
- Organization → break big problems into small pieces
- Readability → give meaningful names to blocks of logic
- Testing → test each piece independently

🔹 Key Concepts

Parameters → inputs the function receives
Return value → output the function gives back
Scope → where a variable can be accessed
Local variable → exists only inside the function
Global variable → exists everywhere (avoid when possible)

---

2. Core Syntax and Rules

🔹 Basic Function
def greet(name):
    print(f"Hello, {name}!")

greet("Mayank") → prints "Hello, Mayank!"

🔹 Return vs Print
def add(a, b):
    return a + b

result = add(3, 5) → result is 8

return gives the value back to the caller.
print just displays it. Not the same thing.

🔹 Parameters
def power(base, exp):
    result = 1
    for _ in range(exp):
        result *= base
    return result

Positional: power(2, 3) → 8
Keyword: power(base=2, exp=3) → 8

🔹 Default Parameters
def greet(name, greeting="Hello"):
    print(f"{greeting}, {name}!")

greet("Mayank") → "Hello, Mayank!"
greet("Mayank", "Hey") → "Hey, Mayank!"

⚠️ DANGER: Never use mutable default arguments.
def f(x=[]):  ← WRONG
    x.append(1)
    return x

f() → [1]
f() → [1, 1]  ← surprise! The list persists between calls.

🔹 Scope
x = 10  # global

def foo():
    x = 5  # local, doesn't affect global
    print(x)

foo() → prints 5
print(x) → prints 10

🔹 *args and **kwargs (preview)
def total(*args):
    return sum(args)

total(1, 2, 3, 4) → 10
